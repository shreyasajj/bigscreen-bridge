# Releases, Install and Auto-update Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tag-driven releases for the bridge and the HA integration. The bridge also gets a one-command TV install, a nightly self-update that won't interrupt playback, and Dependabot security fixes that become pre-releases on their own.

**Architecture:**
- **Workflows:** GitHub Actions handle CI, releases and the Dependabot merge. A Dependabot security PR goes `workflow_run` → merge → `workflow_dispatch` of the release, because pushes and tags made with the built-in token start nothing.
- **On the TV:** a POSIX `install.sh` and a stdlib-only Python updater in the package, driven by a systemd user timer. Each version gets its own venv, and a `venv` symlink selects the current one for rollback.

**Tech Stack:** GitHub Actions, `gh` CLI, POSIX sh, Python 3.12 stdlib (`urllib`, `hashlib`, `tarfile`), dbus-next (already a dependency), systemd user units.

**Spec:** `docs/superpowers/specs/2026-11-17-releases-design.md`

## Global Constraints

- **Repos:** `shreyasajj/bigscreen-bridge`, now public, and `shreyasajj/ha-bigscreen-bridge`.
- **Versions:** release tags are `vX.Y.Z` or `vX.Y.ZrcN`. A pre-release is a version with an `rc` suffix.
- **Release assets:** `bigscreen-bridge-<version>.tar.gz`, `install.sh` and `SHA256SUMS`, where `SHA256SUMS` is in `sha256sum` format.
- **Updater config:** `config.json` key `update` = `{"channel": "stable"|"prerelease", "auto": true|false}`. The default is `{"channel": "stable", "auto": true}`.
- **Timer:** `OnCalendar=*-*-* 03:00`, `RandomizedDelaySec=1h`, `Persistent=true`.
- **Playback wait:** 10 minutes between checks, 4 hours at most. Health check: 60 s after the restart.
- **Venvs:** `~/.local/share/bigscreen-bridge/venvs/<version>`, with the `venv` symlink pointing at one. Keep the last 2.
- **Paths:** releases unpack to `~/.local/share/bigscreen-bridge/releases/<version>`, and the status screen goes to `~/.local/share/bigscreen-status`.
- **Runtime:** the bridge runtime stays at Python `>=3.12`, and nothing needs sudo.
- **Pip:** no pip version updates in `dependabot.yml`.
- **Privacy:** the updater never logs or prints the token.

## Review Focus

1. **GitHub API rate-limited or offline** (403/429/URLError): the updater logs one line and exits 0 without touching the install. The test is in Task 2.
2. **Checksum mismatch or archive path traversal** (`../` members or absolute paths): the updater refuses and nothing is unpacked. The test is in Task 2.
3. **Bridge not on the bus** (Status unreachable) during the playback check: treat as "not playing" and proceed, since there is nothing to interrupt. The test is in Task 2.
4. **Re-running `install-tv.sh` on a TV with a real `venv` directory** (the current TV): it migrates without losing `config.json` or `clients.json`. The test is in Task 3, a shell test against a temporary HOME.
5. **Dispatch with no prior stable release** (the first ever pre-release): the next version becomes `<pyproject version>rc1`. The test is in Task 4 (`next_prerelease`).
